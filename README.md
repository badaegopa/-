# 🌲 숲속 오솔길 보물찾기 — 로또 6/45 번호 생성기

밤 숲의 오솔길을 따라 숨겨진 상자를 열어 로또 번호를 만드는 브라우저 게임입니다.
설치·빌드 없이 `index.html` 하나만 열면 바로 실행됩니다.

## 게임 방식

1. **"오늘 당신의 운은 좋습니까?"** — 좋음 / 보통 / 나쁨 중 하나를 고르면 버프를 받습니다.
2. 숲에는 **45개의 상자**가 있고, 각 상자에는 **1~45 번호가 하나씩** 들어 있습니다(중복 없음).
3. 상자들은 **오솔길(간선)** 로 이어져 있습니다. **멀리 있는 상자를 눌러도** 되며,
   **최단거리 경로**를 따라가고 그만큼 걸음이 깎입니다. 지나치는 상자는 열리지 않고
   **도착한 상자만** 열립니다. 지나온 길은 황금색 선으로 이어지며 빛납니다.
   도달 가능한 상자 위에는 **`N보`** 가 표시됩니다.
4. 이동에는 **걸음(이동력)** 이 듭니다. 짧은 길은 1보, 먼 길은 2보.
   **걸음은 매 판 18보로 리셋**되며, 버프와 무관하게 같습니다.
5. **숫자는 끝까지 보이지 않습니다.** 상자에 도착하면 선택 없이 그대로 담기고,
   슬롯에는 🔒 만 찍힙니다. 열기 전에도 숫자에 대한 힌트는 어디에도 없습니다 —
   보이는 것은 **상자의 등급(색)** 뿐입니다.
6. **여섯째를 담는 순간** 화면이 **숲 전체로 물러나면서 45개 상자가 모두 열립니다.**
   내가 담은 여섯은 금빛 테두리로, 나머지는 흐리게 표시되고, 토템 조각이 나왔던
   자리에는 토템이 함께 남습니다. **2초 뒤** 결과 창으로 넘어갑니다.
7. 결과창에서 새로고침 없이 **바로 재도전**할 수 있습니다
   (같은 버프로 다시 / 운 다시 묻기). 매번 지도와 번호가 새로 생성됩니다.

지나친 상자는 지도에 회색으로 흐려지고 사선이 그어져 남습니다.

걸음이 다해 더 갈 수 없으면 **"숲의 바람에 맡기기"** 로 남은 번호를
아직 열지 않은 상자 중에서 무작위로 채울 수 있습니다.

## 🎯 적중 명예의 전당

완주할 때마다 티켓이 **회차·발행 번호·발행 시각과 함께** 발행됩니다.

- 티켓은 발행 시점 기준 **다음 추첨 회차**에 응모됩니다 (매주 토요일 20:45 KST).
- 추첨일이 지나면 앱을 켤 때 **자동으로 채점**됩니다.
- 6개=1등, 5+보너스=2등, 5개=3등, 4개=4등, 3개=5등.
- 순위는 **적중 개수 → 등수 순**이며, **이번 회차**와 **주차 누적** 두 가지로 봅니다.
- 🎫 내 티켓함에서 회차별 상태(추첨 대기 / 적중 / 낙첨)를 볼 수 있습니다.

### 왜 '당첨금 순위'가 아니라 '적중 순위'인가

앱이 아는 것과 모르는 것을 구분했기 때문입니다.

| 앱이 아는 것 | 앱이 모르는 것 |
|---|---|
| 번호를 **언제 발행했는지** | 사용자가 그 번호로 **실제 복권을 샀는지** |
| 회차 당첨번호와 **몇 개 맞았는지** | 사용자가 **당첨금을 받았는지** |

"○○님 25억 당첨"이라고 쓰면 모르는 쪽을 단정하게 되고, 미끼로 오인되기 쉽습니다.
그래서 순위의 단위를 **적중**으로 두고, 금액은 *그 회차에 공표된 등수별 수령액*으로만
표기합니다. 개인이 받았다고 주장하지 않습니다.

**가짜 이용자를 넣지 않습니다.** 서버 연결 전에는 이 기기의 실제 기록만 보여주고,
비어 있으면 비어 있다고 말합니다.

**발행 증명** — 티켓마다 발행 번호(`#02E956EF`)와 발행 시각이 붙고, 순위에
"추첨 2일 전 발행"으로 표시됩니다. 추첨 *전에* 번호가 기록됐다는 표시라
사후 조작이 아님을 보이는 장치입니다. 다만 **서버가 그 기록을 보관해야
실제 효력이 생깁니다** — 기기 안 값은 고칠 수 있으니까요.

### 보관 정책 — 로그만 누적

용량이 늘지 않도록 원본을 오래 들고 있지 않습니다.

| 대상 | 보관 |
|---|---|
| 티켓 원본 (번호 6개 · 발행 번호 · 발행 시각) | **최근 1회차분만.** 다음 회차가 추첨되면 폐기 |
| 적중 로그 `{회차, 등수, 적중 개수}` | **영구 누적.** 회차마다 한 줄씩 |
| 당첨 금액 | **저장하지 않음.** 회차 정보에서 등수로 다시 구함 |

로그 한 줄은 `{"r":1237,"k":3,"h":5}` — **23바이트 남짓**입니다. 1000회차를
쌓아도 23KB라 사실상 늘지 않습니다.

부작용 하나: **발행 증명(#번호·발행 시각)은 원본이 살아 있는 동안만 보입니다.**
한 주가 지나면 순위에는 "1237회 · 5개 적중"만 남고 증명 줄이 사라집니다.
증명을 오래 보이게 하려면 서버가 발행 로그를 따로 보관해야 합니다.

> ⚠️ **현재는 이 기기 안에서만 돌아갑니다.** 여러 사용자를 한 순위표에 모으려면
> 서버가 필요합니다. 서버 연결 전에는 회차 번호로 고정된 **모의 추첨**으로
> 채점하며, 실제 동행복권 당첨번호가 아닙니다. 화면 곳곳에 「모의」 배지가
> 붙습니다. 서버 연동은 [PLAY.md](PLAY.md)의 *당첨 순위표* 절 참고.

## 🗿 행운의 토템

12조각짜리 토템 퍼즐입니다.

- **한 판에 정확히 한 조각**이 나옵니다. 여섯 상자 중 **어느 상자에서 나올지는 무작위**입니다.
- 숫자를 공개하는 2초 동안, 조각이 나왔던 상자 위에 **토템이 함께 표시**됩니다.
- 조각은 판을 넘어 누적되고, 시작 화면과 HUD에서 진행도를 볼 수 있습니다.
- **12조각을 다 모으면** → **전체 황금상자 모드 1회권**이 되고 **토템은 소멸**합니다.
  (조각이 0으로 리셋되어 다시 모으기 시작합니다)

### 전체 황금상자 모드

숲의 **45개 상자가 모두 황금 상자**가 됩니다. 담으면 걸음 +4, 지나치기는 공짜.
**단 한 판**만 쓸 수 있고, 숲에 들어가기 전 화면에서 사용 여부를 고릅니다.
이 모드에서는 별을 쓰지 않습니다.

## 🎲 주사위 상자

오솔길 **중간**에 여섯 개가 끼워져 있습니다. 상자가 아니라 **길 위의 사건**입니다.

- 도착하면 주사위가 굴러 **1~6**이 나옵니다.
- 나온 눈만큼 **무작위 오솔길로 끌려갑니다.** 어디로 떨어질지는 모릅니다.
- **걸음은 한 보도 들지 않습니다** — 이게 "행운"인 대목입니다.
- 끌려가는 동안 지나치는 상자는 열리지 않고, **도착한 자리의 상자만** 열립니다.
- **후퇴하지 않습니다.** 지나온 자리는 다시 밟지 않고, 출발점에서 **최대한 멀어지는**
  갈래 중에서 무작위로 골라 갑니다.
- 도착한 곳이 또 주사위 상자면 한 번 더 굴립니다(최대 3연속).
- 한 번 굴린 상자는 나온 눈을 남긴 채 꺼집니다.

계획한 경로가 통째로 헝클어지는 대신 걸음을 벌게 되는, 판을 흔드는 요소입니다.

## 상자 등급

상자는 색으로 등급이 구분됩니다. **어디로 갈지, 무엇을 지나칠지**의 기준이 됩니다.

| 등급 | 상자 | 분포 | 담기 | 지나치기 |
|---|---|---|---|---|
| 하 | 낡은 나무 상자 (갈색) | 24개 | 보너스 없음 | 1보 |
| 중 | 은장 상자 (은색) | 14개 | 걸음 +1 | 1보 |
| 상 | 붉은 옻칠 상자 (붉은색+금테) | 7개 | 걸음 +2 | 2보 |
| ⭐ | 행운의 상자 (황금·광채) | 광고로 획득한 수만큼 | 걸음 +4 | 공짜 |

> **등급은 숫자 크기와 아무 상관이 없습니다.** 번호 배정과 등급 배정은 각각 독립적으로
> 섞이며, 45개 상자에 무작위로 흩어집니다. 등급에 따라 달라지는 것은
> **걸음 보너스와 지나치기 비용뿐**입니다.
> (`shuffled45()`로 번호를, 별도 셔플로 등급을 배정 — 4만 회 시뮬레이션에서
> 번호–등급 카이제곱 80.2, 자유도 88로 독립성 확인)

## ⭐ 별 · 👣 보유 걸음 · 광고

광고 1회를 끝까지 보면 **별 +1 · 걸음 +2**를 받습니다(도중에 닫으면 보상 없음).
**둘 다 상한이 없고, 판이 바뀌어도 사라지지 않습니다.**

| | 리셋 | 쓰임 |
|---|---|---|
| 기본 걸음 | **매 판 18보로 리셋** | 이동·지나치기 |
| 👣 보유 걸음 | 리셋 안 됨 (창고에 누적) | 막혔을 때 꺼내 씀 |
| ⭐ 별 | 리셋 안 됨 (창고에 누적) | 황금 상자로 배치 |

### 별을 몇 개 놓을지 고른다

숲에 들어가기 전 **"별을 황금 상자로 바꿔 놓으시겠습니까?"** 를 묻고
**0~6개** 중에서 고릅니다.

- **고른 수만큼 별이 소모됩니다.** 찾지 못해도 돌아오지 않습니다.
- **0개도 됩니다.** 이번 판은 아끼고 별을 모아두는 선택입니다.
- 보유한 별보다 많이 고를 수는 없고, 한 판 최대는 6개입니다.

한 판에 몰아 쓸지 아껴 모을지를 **매 판 직접 정하는** 구조입니다.

### 걸음이 막혔을 때

판이 끝나지 않습니다. 실패 화면에서 두 가지를 고를 수 있습니다.

- **👣 보유 걸음 쓰기** — 창고에 쌓아둔 걸음을 한 번에 꺼내 씁니다 (HUD 칩을 눌러도 됩니다).
- **📺 광고 보기** — 별 +1 · 걸음 +2를 받아 이어서 갑니다.

보유량은 브라우저(localStorage)에 저장되며, Play 게임즈에 로그인하면
**저장된 게임(Snapshots)** 으로 계정에 동기화됩니다.

> ⚠️ 현재 광고는 **동작 확인용 자리표시자**입니다(5초 카운트다운 + "광고 영역 · 샘플" 표시).
> 실제 광고 네트워크를 붙이려면 `runAd()` 부근의 타이머를 광고 SDK의 *재생 완료* 콜백으로
> 바꾸면 그대로 연결됩니다. 소스에 해당 지점을 주석으로 표시해 두었습니다.

## 지나칠 이유

상자를 열면 선택 패널이 **왜 지나칠 만한지**를 알려줍니다.

- **등급과 효과** — "낡은 나무 상자 · 걸음 보너스 없음 · 지나치기 1보"
- **구성 메모** — 이미 담은 번호와 견주어 한 줄:
  - "이미 21~30 구간을 2개 담았다 — 번호가 한쪽으로 쏠린다"
  - "24번과 붙는 연속 번호다"
  - "담으면 홀수만 5개 — 홀짝이 치우친다"
  - "아직 비어 있는 11~20 구간이다 — 고르게 퍼진다"

> 구성 메모는 **게임 진행을 돕는 연출**입니다. 로또 추첨은 매 회 독립이므로
> 번호 구성으로 당첨 확률이 달라지지 않습니다.

| 🧭 보통 | 든든한 나침반 | 이웃 상자의 **등급이 글자로** 표시 · 상자를 담을 때마다 **걸음 +1** |

주사위 상자의 강제 이동은 어느 버프에서도 걸음을 쓰지 않습니다.

운이 좋다고 답하면 적게 주고 자주 눈감아 주고, 나쁘다고 답하면 넉넉하고
예측 가능한 길을 내어주는 구조입니다.

## 기술

- 의존성 없는 단일 HTML 파일 (Canvas 2D + WebAudio)
- 번호는 `crypto.getRandomValues` 기반 Fisher–Yates 셔플로 섞습니다
  (모듈로 편향 제거 포함). 45개 상자에 1~45를 중복 없이 배정합니다.
- 지도는 9×5 격자를 흔들어 배치한 뒤 인접·대각 간선을 확률적으로 연결하고,
  union-find로 끊긴 덩어리를 이어 **항상 연결된 그래프**를 보장합니다.
- 데스크톱/모바일 반응형, 오프라인 동작
- **모바일 최적화**: 핀치 줌·드래그 팬 제스처, 화면 크기별 HUD 압축(세로/가로 대응),
  지도 위 글자는 확대율을 보정해 축소해도 읽히며, 작은 화면에서는 장식 물량과
  픽셀 밀도를 낮춰 렌더 비용을 줄입니다. 인앱 웹뷰를 고려해 오버스크롤·더블탭 확대를
  막고 `setPointerCapture` 실패에도 제스처가 이어지도록 처리했습니다.

## Google Play 목업 셸

앱으로 출시했을 때의 흐름을 폰에서 그대로 눌러볼 수 있게 목업 계층이 들어 있습니다.
**아직 실제 SDK는 붙어 있지 않습니다** — 전부 목업이며, 교체 지점은 [PLAY.md](PLAY.md)에 정리했습니다.

- **스플래시** — 앱 아이콘·이름이 뜨는 실행 화면
- **Play 게임즈 로그인** — 시작 화면 상단 (목업 프로필)
- **리워드 광고** — AdMob 리워드 형식의 전체화면. 끝까지 봐야 보상
- **업적 7종** — 첫 탐험 / 행운을 줍다 / 까다로운 눈 / 아슬아슬 / 숲의 단골 / 숲의 장난(주사위 6) / 첫 당첨
- **적중 명예의 전당** — 회차별·누적 적중 상위 5명 (서버 연결 전에는 내 기록만)
- **안드로이드 뒤로가기** — 모달을 하나씩 닫음 (앱 종료 대신)

우측 상단 **🧪 목업 설정**에서 광고 결과(정상·재고없음·오류), 광고 길이,
로그인 상태, 기기 프레임(상태바·노치)을 바꿔가며 검증할 수 있습니다.
배포 빌드에서는 이 버튼을 제거하세요.

### PWA로 설치해 보기

`manifest.webmanifest` + `sw.js` 가 포함되어 있어, HTTPS로 올린 뒤 Chrome에서
"앱 설치"를 누르면 전체화면 앱처럼 실행되고 **오프라인에서도 동작**합니다.

```
npm run serve      # http://<PC-IP>:8080 으로 폰에서 접속
```

### 안드로이드 빌드

```
npm install
npm run cap:add    # www/ 생성 + Capacitor 안드로이드 프로젝트 생성
npm run cap:open   # Android Studio 열기
```

스토어 등록 자산(아이콘·피처그래픽·스크린샷)은 `play-assets/` 에 들어 있습니다.
