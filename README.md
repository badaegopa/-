# 🌲 숲속 오솔길 보물찾기 — 로또 6/45 번호 생성기

밤 숲의 오솔길을 따라 숨겨진 상자를 열어 로또 번호를 만드는 브라우저 게임입니다.
설치·빌드 없이 `index.html` 하나만 열면 바로 실행됩니다.

## 게임 방식

1. **"오늘 당신의 운은 좋습니까?"** — 좋음 / 보통 / 나쁨 중 하나를 고르면 버프를 받습니다.
2. 숲에는 **45개의 상자**가 있고, 각 상자에는 **1~45 번호가 하나씩** 들어 있습니다(중복 없음).
3. 상자들은 **오솔길(간선)** 로 이어져 있습니다. 이어진 길로만 이동할 수 있고,
   지나온 길은 **황금색 선으로 이어지며 빛납니다**.
4. 이동에는 **걸음(이동력)** 이 듭니다. 짧은 길은 1보, 먼 길은 2보.
5. 상자에 도착하면 열리며 번호가 공개되고, **담을지 지나칠지 고릅니다.**
   - **✋ 담기** — 번호를 슬롯에 넣습니다.
   - **🍃 지나치기 (1보)** — 마음에 안 드는 번호를 버립니다.
     걸음 1보가 들고, 그 상자는 다시 열 수 없습니다.
   - 걸음이 1보도 없으면 지나칠 수 없어 담아야 합니다.
6. **6개를 담으면 번호 생성 완료 창**이 뜹니다.
7. 결과창에서 새로고침 없이 **바로 재도전**할 수 있습니다
   (같은 버프로 다시 / 운 다시 묻기). 매번 지도와 번호가 새로 생성됩니다.

지나친 상자는 지도에 회색으로 흐려지고 사선이 그어져 남습니다.
결과창에는 지나친 상자 개수도 함께 기록됩니다.

걸음이 다해 더 갈 수 없으면 **"숲의 바람에 맡기기"** 로 남은 번호를
아직 열지 않은 상자 중에서 무작위로 채울 수 있습니다.

## 버프

| 대답 | 버프 | 효과 |
|---|---|---|
| 🍀 좋음 | 행운의 순풍 | 시작 **20보** · 이동 시 **35% 확률로 걸음 미소모** · 담을 때 **25% 확률로 걸음 +3** |
| 🧭 보통 | 든든한 나침반 | 시작 **26보** · 이웃 상자의 **번호 구간(작음·중간·큼) 미리 표시** · 담을 때마다 **걸음 +1** |
| 🕯 나쁨 | 액땜의 등불 | 시작 **34보** · **모든 오솔길이 1보로 고정** · 행운 보정 없음(계산이 어긋나지 않음) |

운이 좋다고 답하면 채비는 적게 주고 행운으로 갚고,
나쁘다고 답하면 넉넉하고 예측 가능한 길을 내어주는 구조입니다.

## 조작

| 입력 | 동작 |
|---|---|
| 상자 클릭·터치 | 오솔길로 이어진 이웃 상자로 이동 |
| 방향키 / WASD | 그 방향의 이웃 상자로 이동 |
| `Enter` · `1` · `Y` | 열린 상자 **담기** |
| `Esc` · `2` · `N` | 열린 상자 **지나치기** |
| `M` 또는 🗺 전체지도 | 숲 전체 보기 ↔ 따라가기 전환 |
| 📜 | 최근 30회 기록 (localStorage) |
| 🔊 | 효과음 켜기/끄기 |

## 기술

- 의존성 없는 단일 HTML 파일 (Canvas 2D + WebAudio)
- 번호는 `crypto.getRandomValues` 기반 Fisher–Yates 셔플로 섞습니다
  (모듈로 편향 제거 포함). 45개 상자에 1~45를 중복 없이 배정합니다.
- 지도는 9×5 격자를 흔들어 배치한 뒤 인접·대각 간선을 확률적으로 연결하고,
  union-find로 끊긴 덩어리를 이어 **항상 연결된 그래프**를 보장합니다.
- 데스크톱/모바일 반응형, 오프라인 동작

## 실행

```
# 파일을 그대로 열거나
open index.html

# 로컬 서버로
npx http-server .
```
